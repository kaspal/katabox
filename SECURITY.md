# Security policy

KataBox runs user code on the user's machine inside a sandbox. If you find a way for code run by KataBox to escape the sandbox, reach the network, read or write files outside its temporary folder, or exhaust the machine despite the limits, please report it privately.

**Do not open a public issue.** Use GitHub's "Report a vulnerability" (private security advisories) on this repository.

We aim to acknowledge reports within 7 days.
