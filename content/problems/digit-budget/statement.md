A lottery prints ticket numbers from 1 to `limit`. A ticket is **lucky** when the digits of its number add up to exactly `total`.

Return how many lucky tickets there are.

### Example 1

```
limit = 30, total = 5
Output: 3
```

The tickets 5, 14 and 23.

### Example 2

```
limit = 100, total = 1
Output: 3
```

The tickets 1, 10 and 100.

### Example 3

```
limit = 9, total = 10
Output: 0
```

### Constraints

- 1 ≤ limit ≤ 10¹⁵
- 1 ≤ total ≤ 135
