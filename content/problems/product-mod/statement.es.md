Tomás sigue el crecimiento de un cultivo de bacterias: cada hora la población se multiplica por un factor, y quiere conocer el multiplicador final. Su script coincide con su cuaderno en las pruebas cortas, pero en las largas, con factores grandes, los números dejan de cuadrar.

Dado `nums`, devuelve el producto de todos sus valores módulo 1 000 000 007 (10⁹ + 7).

El editor empieza con ese código. Encuentra el error y corrígelo.

### Ejemplo 1

```
nums = [6, 7, 10]
Salida: 420
```

### Ejemplo 2

```
nums = [5, 2, 8, 8]
Salida: 640
```

### Ejemplo 3

```
nums = [2, 6, 3, 5]
Salida: 180
```

### Restricciones

- 1 ≤ nums.length ≤ 10⁵
- 1 ≤ nums[i] ≤ 10⁹
