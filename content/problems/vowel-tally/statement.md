A typesetter wants to know how many vowels a line of text uses. The vowels are `a`, `e`, `i`, `o` and `u`, in lowercase or uppercase; `y` does not count.

Given a line of `text`, return the number of vowels in it.

### Example 1

```
text = "Rain in Spain"
Output: 5
```

The vowels are a, i, i, a, i.

### Example 2

```
text = "rhythm"
Output: 0
```

### Example 3

```
text = "AEIOU aeiou!"
Output: 10
```

### Constraints

- 0 ≤ text.length ≤ 10⁵
- text has printable ASCII characters only (letters, digits, spaces and punctuation).
