Un tipógrafo quiere saber cuántas vocales usa una línea de texto. Las vocales son `a`, `e`, `i`, `o` y `u`, en minúscula o mayúscula; la `y` no cuenta.

Dada una línea de texto, `text`, devuelve el número de vocales que contiene.

### Ejemplo 1

```
text = "Rain in Spain"
Salida: 5
```

Las vocales son a, i, i, a, i.

### Ejemplo 2

```
text = "rhythm"
Salida: 0
```

### Ejemplo 3

```
text = "AEIOU aeiou!"
Salida: 10
```

### Restricciones

- 0 ≤ text.length ≤ 10⁵
- text solo tiene caracteres ASCII imprimibles (letras, dígitos, espacios y signos de puntuación).
