Given an array of integers `nums` and an integer `target`, return the indices of the two numbers that add up to `target`.

Exactly one pair is a valid answer, and you may not use the same element twice. Return the two indices in any order.

### Example 1

```
nums = [5, 8, 12, 1, 3], target = 15
Output: [2, 4]
```

### Example 2

```
nums = [7, -3, 10, 5], target = 2
Output: [1, 3]
```

### Constraints

- 2 ≤ nums.length ≤ 10⁵
- −10⁹ ≤ nums[i], target ≤ 10⁹
- Exactly one valid answer exists.
