Una estación meteorológica anota la temperatura, en grados enteros, varias veces al día. La **oscilación** del día es la diferencia entre la lectura más cálida y la más fría.

Dadas las lecturas del día, `readings`, devuelve la oscilación.

### Ejemplo 1

```
readings = [12, 18, 7, 15]
Salida: 11
```

La lectura más cálida es 18 y la más fría, 7.

### Ejemplo 2

```
readings = [-3, -8, -1]
Salida: 7
```

### Ejemplo 3

```
readings = [20]
Salida: 0
```

### Restricciones

- 1 ≤ readings.length ≤ 10⁵
- -100 ≤ readings[i] ≤ 100
