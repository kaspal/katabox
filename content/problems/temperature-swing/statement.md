A weather station records the temperature, in whole degrees, several times a day. The **swing** of the day is the difference between the warmest and the coldest reading.

Given the day's `readings`, return the swing.

### Example 1

```
readings = [12, 18, 7, 15]
Output: 11
```

The warmest reading is 18 and the coldest is 7.

### Example 2

```
readings = [-3, -8, -1]
Output: 7
```

### Example 3

```
readings = [20]
Output: 0
```

### Constraints

- 1 ≤ readings.length ≤ 10⁵
- -100 ≤ readings[i] ≤ 100
