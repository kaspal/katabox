# KataBox 1.0.0-beta.2

KataBox is a free, open-source desktop app for coding practice. You solve problems in
Python, JavaScript/TypeScript, PHP, Rust or SQL, and your code runs on your own machine in
a sandbox, with no account and no telemetry. This is the first public release, a beta for
Windows 10/11.

## Highlights

- **A new Home:**
  - today's session: continue your draft, the daily problem, a daily kata and the next
    step on your learning path, each with a time estimate;
  - your week and your solved count;
  - your path as a track of Learn topics, and what to watch next.
- **A new icon and a short startup animation.** The animation plays in full only on the
  first start after an install or update (Settings → Appearance → Startup animation).
- **273 problem packages:** 233 original problems (function, stdin/stdout program and SQL
  problems, including 24 "fix the bug" problems that start from buggy code) and 40 harder
  follow-up variants.
- **Learn:** 118 animated topics in 14 subjects, 8 sets of "read the code" exercises, and
  3 learning paths.
- **Practise in new ways:**
  - kata drills against the clock;
  - a skill rating per pattern;
  - study plans (with a calendar file);
  - a mistake journal and reflections;
  - focus sessions;
  - a stress test against your own brute force;
  - visual builders for custom tests.
- **Problem packs and classroom mode:**
  - import verified `.kbpack` problem sets, or make your own with the in-app problem
    editor;
  - teachers can hand out assignments and collect results files.
- **Three interface languages:** English, Spanish and now Portuguese (Brazil).
- **A tidier app:**
  - Progress and Settings in tabs and sections, with search;
  - snippets and global search (Ctrl+Shift+P);
  - automatic backups;
  - the window reopens where you left it.
- **Still offline and private:** after a language is downloaded, everything runs
  locally. The only network use is downloading runtimes and language servers from
  pinned, verified URLs.

See [CHANGELOG.md](https://github.com/kaspal/katabox/blob/v1.0.0-beta.2/CHANGELOG.md) for the full list.

## Install

Windows 10 or 11, x64.

- **Most people:** download `KataBox_1.0.0-beta.2_x64-setup.exe` and run it. It installs
  for your user only and needs no administrator rights.
- **Managed machines:** `KataBox_1.0.0-beta.2_x64_en-US.msi` or
  `KataBox_1.0.0-beta.2_x64_es-ES.msi` install for all users and need administrator
  rights.
- **Languages:** on first start, KataBox asks which languages to install and downloads
  them. Python is about 100 MB to download; Rust is the largest at about 250 MB. After
  that, KataBox works offline.

## The installer is unsigned

This beta is **not code-signed yet**, so the first time you run the installer Windows
SmartScreen may show **"Windows protected your PC"**. To install anyway:

1. Click **More info**.
2. Check that the app is `KataBox_1.0.0-beta.2_x64-setup.exe`, with publisher
   "Unknown publisher".
3. Click **Run anyway**.

Why: code-signing certificates are tied to an identity and a yearly cost, and the
project is setting up free signing for open-source projects. Until then, you can
check that your download is the published one by comparing its SHA-256 with the
checksums below (PowerShell: `Get-FileHash .\KataBox_1.0.0-beta.2_x64-setup.exe`).
Signing is planned for a later beta.

## Upgrading from 1.0.0-beta.1

Install the new version over the previous one. Your progress, drafts, notes and settings
are kept, and "What's new" shows what changed. There is no automatic update yet. Exports
made with beta.1 still import.

## Known issues

The full list is in [docs/known-issues.md](https://github.com/kaspal/katabox/blob/v1.0.0-beta.2/docs/known-issues.md). The main ones:

- The installers are unsigned, so Windows SmartScreen warns the first time you run them
  (see above).
- The debugger supports Python and JavaScript/TypeScript only, not PHP or Rust.
- KataBox is Windows-only for now; Linux builds are not released yet.
- Problems and Learn topics are in English and Spanish; with the Portuguese interface
  you pick one of the two for content.

## Reporting a security issue

Please do not open a public issue. Use the repository's **Security** tab →
**Report a vulnerability** (see [SECURITY.md](https://github.com/kaspal/katabox/blob/v1.0.0-beta.2/SECURITY.md)).
