# KataBox 1.0.0-beta.1

KataBox is a free, open-source desktop app for coding practice. You solve problems in
Python, JavaScript/TypeScript, PHP, Rust or SQL, and your code runs on your own machine in
a sandbox, with no account and no telemetry. This is the first public release, a beta for
Windows 10/11.

## Highlights

- **209 original problems:** 150 function problems, 35 stdin/stdout program problems and
  24 SQL problems, in 27 patterns from easy to hard.
- **Learn:** 118 animated topics in 14 subjects, with theory, step-by-step sample code,
  quizzes and three learning paths.
- **Replay debugger and visualizer** for Python and JavaScript/TypeScript: breakpoints,
  stepping back and forth, and pictures of your arrays, lists, trees and graphs.
- **Complexity profiler:** an estimate of your solution's time complexity on 95 problems.
- **Practice tools:** a daily problem and streak, spaced-repetition reviews, timed mock
  interviews, personal lists and a progress page.
- **Failing-test shrinker:** turns a failing test into a smaller one that still fails.
- **Offline and private:** after a language is downloaded, everything runs locally. The
  only network use is downloading runtimes and language servers from pinned, verified
  URLs.
- **English and Spanish,** with keyboard shortcuts, high contrast and reduced motion.

See [CHANGELOG.md](https://github.com/kaspal/katabox/blob/v1.0.0-beta.1/CHANGELOG.md) for the full list.

## Install

Windows 10 or 11, x64.

- **Most people:** download `KataBox_1.0.0-beta.1_x64-setup.exe` and run it. It installs
  for your user only and needs no administrator rights.
- **Managed machines:** `KataBox_1.0.0-beta.1_x64_en-US.msi` or
  `KataBox_1.0.0-beta.1_x64_es-ES.msi` install for all users and need administrator
  rights.
- **SmartScreen warning:** this beta is not code-signed, so Windows may show "Windows
  protected your PC". Click **More info**, then **Run anyway**.
- **Languages:** on first start, KataBox asks which languages to install and downloads
  them. Python is about 100 MB to download; Rust is the largest at about 250 MB. After
  that, KataBox works offline.

## Upgrading

Install the new version over the previous one. Your progress, drafts and settings are
kept. There is no automatic update yet.

## Known issues

The full list is in [docs/known-issues.md](https://github.com/kaspal/katabox/blob/v1.0.0-beta.1/docs/known-issues.md). The main ones:

- The installers are unsigned, so Windows SmartScreen warns the first time you run them.
- The debugger supports Python and JavaScript/TypeScript only, not PHP or Rust.
- KataBox is Windows-only for now; there is no Linux build in this release.
